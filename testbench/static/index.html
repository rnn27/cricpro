1. Upload a clip

Record one delivery with your phone's normal camera in 240 fps slow-motion, then pick the file here. Trim it to the delivery (a few seconds). iPhone tip: if the picker re-compresses the video, send the original to the PC (AirDrop/Files/cable) and use this page on the PC instead.

2. Mark the stumps

Scrub to a frame where both sets of stumps are clearly visible. Tap the point on the main picture, then fine-tune in the zoomed square (tap inside it to move the cross). Order below.

frame

3. Mark the release frame

Find the last frame where the ball is still in the bowler's hand (or the first where it has just left). Being 1–2 frames off barely changes the speed.
